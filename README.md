# MoveWorth — 海外移住後の資産・生活費シミュレーター

**公開サービス:** https://www.moveworthapp.com/  
**シミュレーター:** https://www.moveworthapp.com/simulate

MoveWorthは、海外移住を検討する人が、移住前後の収入・税金・家賃・生活費・為替・インフレを入力し、将来の資産推移を比較できるWebサービスです。個人開発として制作し、公開後もデータ整備と機能改善を続けています。

## 主な機能

- **移住シミュレーション:** 現在地と移住先の収入・支出などを入力し、複数年の資産推移を計算
- **可視化・比較:** グラフによる結果表示と、プランに応じた追加国との比較
- **シミュレーション履歴:** ログインユーザーごとの結果保存・再確認
- **認証・プラン:** Supabaseを利用したユーザー管理とプラン別の機能制御
- **AIレポート:** シミュレーション結果をもとにした文章レポート生成（対象プランでは利用回数制御あり）
- **多言語・関連コンテンツ:** 日本語・英語のUI、国別情報・留学関連情報、SEO対応

※利用できる機能はプランによって異なります。計算結果は入力条件に基づく試算であり、将来の資産や税額を保証するものではありません。

## 設計・開発上のポイント

### 1. 入力と計算ロジックの分離

`src/app/simulate/page.tsx` の入力UIから、`src/lib/simulation/basic-calculator` の計算処理を呼び出す構成です。結果表示は独立したコンポーネントに分けています。

### 2. 条件を変えた国別比較

年収・家賃・生活費・税率・為替・インフレなどの条件を設定してシミュレーションします。複数国比較では、共通条件を保ちながら移住先固有の入力を差し替えます。

### 3. データの根拠と更新

生活費・収入等の国別データは、Eurostatや各国の公的統計などを参照して整備しています。出典・対象年・計算前提が異なるデータを扱うため、表示値とユーザー入力を区別することを重視しています。

### 4. API側のアクセス制御

AIレポート生成APIでは、認証トークンの確認、対象プランの検証、月次利用回数チェックを実装しています。APIキーなどの秘密情報はサーバー側の環境変数で管理します。

## ローカル実行

Node.jsとnpmが必要です。

```bash
npm install
npm run dev
```

※外部API・認証など一部機能やビルドには、環境変数・サービス設定が必要な場合があります。

## テスト・検証

```bash
npm run lint
npm run build
```
